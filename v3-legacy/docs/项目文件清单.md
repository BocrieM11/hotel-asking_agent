## ⚙️ 引擎核心 (engine/)

### 🔌 入口 & 服务

|------|------|------|
| `api-server.js` | 12KB | **HTTP API 主入口**。路由: /chat(Web)/engine/chat(API)/health/engine/config/engine/reload。含鉴权、限流、健康检查 |

| 文件 | 大小 | 对应BRD步骤 | 说明 |

| `faq-handler.js` | 70KB | 核心处理器 | **问询核心**。FAQ主题检测(350+同义词)、天气/时间/酒店呼叫处理、边界检查 |
| `nlu-adapter.js` | 3.5KB | §9步骤(3) | **NLU适配器**。天气>时间>酒店呼叫>FAQ 路由 |
| `intent-arbiter.js` | 5.1KB | §9步骤(5) | **意图裁决器**。多候选评分排序+冲突检测 |
| `entity-resolver.js` | 6.9KB | §9步骤(2) | **实体解析器**。位置/设备/场景词表匹配+歧义标记 |
| `slot-validator.js` | 4.3KB | §9步骤(6) | **槽位校验器**。enum/range/clamp校验 |
| `capability-gate.js` | 1.7KB | §9步骤(4) | **能力矩阵门控**。device_type→intent支持校验 |
| `decision-output.js` | 7KB | §9步骤(7)(8) | **决策输出**。BRD §5.2标准格式 |
| `risk-guard.js` | 5.5KB | §7 | **风控红线**。10条全局红线 + 6个意图级策略 |
| `need-clarify.js` | 5KB | §6.1 | **澄清机制**。9种reason_code + 优先级排序 + 字段约束 |
