

# 🏨 酒店问询Agent — 项目周报

> 周期: 2026年6月8日–6月11日 | 汇报人: 问询模块负责人

---

## 一、项目概述

酒店智能Agent共5大模块（控制/问询/点餐/客房服务/酒店呼叫），本人负责**问询子系统**。从零搭建BRD合规的问询引擎，经历三代架构演进，最终交付可本地部署的生产级Agent。

---

## 二、架构演进路线

```
v2.0 ──────── v2.4 ──────── v3.0 ──────── v3.2
规则引擎      BRD合规       LLM Agent    RAG+优化
(6/8)        (6/10)        (6/11)       (6/11)
```

### v2.0–v2.4: 规则引擎时代（6/8–6/10）

**核心思路**: BRD §5-§11全对齐的规则引擎 + LLM润色

| 版本 | 日期 | 核心变更 |
|------|------|----------|
| v2.0 | 6/8 | BRD分析 → 6个问询意图确认 → 55个意图精简为6个 |
| v2.1 | 6/9 | 配置重构(89%/67%/56%精简率) + faq-handler重写(450行) |
| v2.2 | 6/9–6/10 | 混合检索(350+同义词) + 多轮会话(50轮) + LLM生成器 |
| v2.3 | 6/10 | 威尼斯人数据填充(198项) + BRD P0×4修复 + P1×3优化 |
| v2.4 | 6/10 | 安全加固(PM2/鉴权/限流/健康检查) + Web UI |

**v2.4 规模**: 17个源文件，~7000行代码，60+条规则，600+测试用例

### v3.0: 架构革命 — 规则→Agent (6/11)

**核心思路**: 去掉所有规则，LLM自主决策 + 3个Tools

| 改动 | 效果 |
|------|------|
| 删除12个规则引擎文件 | 7000行 → 500行 (-93%) |
| 删除9个配置文件 | 0个JSON配置 |
| 删除350+同义词库 | LLM语义理解替代 |
| 新增 agent.js | LLM Agent + search/weather/time 3个Tools |
| 本地模型 | 切到 Ollama (qwen2.5:7b→14b) |

**不理想**: qwen2.5:14b指令遵循差，常编造数据，偶尔输出泰语

### v3.1–v3.2: 优化完善 (6/11)

| 版本 | 核心变更 |
|------|----------|
| v3.1 | 切DeepSeek API测试 → 质量飞跃 → 发现本地瓶颈 |
| v3.1 | 换模型: deepseek-r1:14b (本地DeepSeek开源版) |
| v3.1 | 知识库恢复 → 37KB/6文件 → 修复KB检索算法(章节匹配) |
| v3.2 | **RAG语义检索**: bge-m3 embedding + 关键词混合检索 |
| v3.2 | **响应缓存**: 高频问题秒回 |
| v3.2 | **历史持久化**: 会话存JSON，刷新不丢 |
| v3.2 | **主动推荐**: 按时段推荐早餐/贡多拉/缆车/夜景 |
| v3.2 | **分析面板**: /health 看 total/cacheSize/indexReady |

## 三、当前状态 (v3.2)

### 技术栈

| 层 | 技术 |
|----|------|
| LLM | deepseek-r1:14b (本地Ollama) |
| 嵌入 | bge-m3:latest (中文语义) |
| 天气 | Open-Meteo (免费) |
| 时间 | 系统时钟 + 时区映射 |
| 知识库 | 6个Markdown文件 (37KB) |
| 检索 | 关键词 + 向量语义 混合检索 (91段落) |
| 前端 | 单文件HTML (中英双语) |
| 部署 | PM2 / Node.js |

### 引擎文件 (5个)

```
engine/
├── agent.js              LLM Agent (RAG+缓存+推荐)
├── api-server.js         HTTP服务 (50行)
├── session-store.js      会话记忆
├── conversation-logger.js 对话日志
├── ecosystem.config.js   PM2配置
└── web-ui.html           Web界面 (中英双语)
```

### 功能边界

```
✅ 酒店知识问答 (20个主题，中英双语)
✅ 天气查询 (Open-Meteo + 澳门默认)
✅ 时间查询 (系统时钟 + 时区)
✅ 多轮对话 (50轮 + 会话持久化)
✅ RAG语义检索 (bge-m3 + 关键词混合)
✅ 响应缓存 (高频问题秒回)
✅ 主动推荐 (按时段)
✅ 对话日志 (Markdown归档)
🚫 客房服务/点餐/设备控制 → 友好引导
```
